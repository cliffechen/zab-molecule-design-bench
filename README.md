# Zab 分子纹理工作台

为 Zab 保健品瓶签设计「单尖 + 双尖」分子纹理的迷你工作台，单个 HTML 文件，双击即可在浏览器打开。

## 文件

- `zab-molecule-bench.html` — 工作台
  - 编辑：在方格上放圆、斜向拖动连接成单尖 / 双尖，规则自动检查（双尖接双尖、Z 形双尖可开关）
  - 生成：默认「颗粒场 · 分子颗粒」，按产品名生成，可换排列、调数量
  - 颜色：19 条功效线的 8 色色彩场，或三色渐变
  - 瓶签对比 / 全系列：预览纹理在瓶签上的效果，色带颜色可输入色号
  - 导出：透明底 PNG、SVG、方案 JSON
- `splash/` — 墨晕、粉雾、分子颗粒习作（透明底 PNG）
  - `splash-generator.html` — 生成器，网址末尾加 `#style=grain&pal=repair&seed=1` 这样的参数
    - style：`ink`（墨晕）、`powder`（粉雾）、`grain`（分子颗粒）
    - pal：`repair`、`sleep`、`energy`、`gut`、`beauty`
    - seed：任意数字

## 几何

方格间距 d，圆半径 r = d(1 − √2/2)；尖由两段半径 d/√2、圆心在相邻格点的圆弧构成，与圆相切并在格子角点收成尖。两个对角的尖在同一角点相接时，弧线连成一条平滑的腰线。
